# Dicionário de Variáveis Utilizadas – IBGE (População)

| Variável | Descrição |
|-----------|-----------|
| ano | Ano de referência do censo/estimativa populacional. |
| id_municipio | Código do município segundo o IBGE. |
| nome_municipio | Nome do município. |
| sigla_uf | Sigla da Unidade Federativa (UF). |
| populacao | População residente estimada para o município no ano de referência. |
