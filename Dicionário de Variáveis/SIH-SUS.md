# Dicionário de Variáveis Utilizadas – SIH-SUS

| Variável | Descrição |
|-----------|------------|
| N_AIH | Número da Autorização de Internação Hospitalar (AIH). Identificador da internação. |
| UF_ZI | Unidade Federativa da Zona de Internação. |
| IDENT | Tipo de AIH (identificação da internação). |
| ANO_CMPT | Ano de competência do processamento da AIH. |
| MES_CMPT | Mês de competência do processamento da AIH. |
| NASC | Data de nascimento do paciente. |
| IDADE | Idade do paciente na internação. |
| SEXO | Sexo do paciente. |
| RACA_COR | Raça/cor autodeclarada do paciente. |
| MUNIC_RES | Município de residência do paciente. |
| DIAG_PRINC | Diagnóstico principal da internação (CID-10). |
| CAR_INT | Caráter da internação (eletiva, urgência etc.). |
| MUNIC_MOV | Município onde ocorreu a internação. |
| CID_ASSO | CID associado à internação. |
| CID_MORTE | CID relacionado ao óbito, quando aplicável. |
| COMPLEX | Complexidade da assistência prestada. |
| DT_INTER | Data de internação hospitalar. |
| DT_SAIDA | Data de saída hospitalar. |
| QT_DIARIAS | Quantidade de diárias cobradas na internação. |
| DIAS_PERM | Tempo de permanência hospitalar (dias). |
| MORTE | Indicador de ocorrência de óbito durante a internação. |
