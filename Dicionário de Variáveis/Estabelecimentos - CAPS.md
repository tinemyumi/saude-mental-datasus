# Dicionário de Variáveis Utilizadas – CNES (CAPS)

| Variável | Descrição |
|-----------|-----------|
| CO_CNES | Código único do estabelecimento no Cadastro Nacional de Estabelecimentos de Saúde (CNES). |
| CO_UNIDADE | Código identificador da unidade de saúde. |
| CO_UF | Código da Unidade Federativa (UF) do estabelecimento. |
| CO_IBGE | Código do município segundo o IBGE. |
| NO_RAZAO_SOCIAL | Razão social do estabelecimento de saúde. |
| NO_FANTASIA | Nome fantasia do estabelecimento. |
| CO_ESFERA_ADMINISTRATIVA | Esfera administrativa responsável pelo estabelecimento (municipal, estadual, federal etc.). |
| CO_ATIVIDADE | Código da atividade principal do estabelecimento. |
| TP_UNIDADE | Tipo de unidade de saúde. |
